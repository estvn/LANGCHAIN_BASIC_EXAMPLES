# Langchain Componentes Clave

# Chains 

- Permiten secuenciar tareas y procesos en flujos de trabajo definidos
- Facilitan la interacción entre diferentes componentes y herramientas
- Optimizan el manejo de tareas complejas y multifacéticas.

# Memory

- Mejora la capacidad del sistema para recordar interacciones previas
- Soporta la generación de respuestas más precisas y contextuales
- Crucial para aplicaciones con interacciones a largo plazo

# Tools 

- Extiende las capacidades de los LLM con funciones específicas
- Incluye herramientas para búsqueda, análisis y más
- Integra APIs y servicios externos para funciones adicionales
