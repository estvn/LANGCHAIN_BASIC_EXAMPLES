# Ecosistema Langchain

# LangGraph

- Es una biblioteca diseñada para construir aplicaciones multi-actor y con estado utilizando modelos de lenguaje grandes (LLM), basada en Langchain.

- Extiende el Langchain Expression Language (LCEL) con la capacidad de coordinar múltiples cadenas o actores a través de múltiples etapas de computación de manera cíclica.

- Orientado a facilitar el manejo de ciclos y tareas repetitivas dentro de las aplicaciones

- **Ideal para implementar comportamientos de agentes inteligentes que requieren decisiones y acciones iterativas basadas en el análisis continuo y la entrada de datos en tiempo real.**

# LangSmith 

- Es una plataforma unificada para depurar, probar monitorear aplicaciones de modelos de lenguaje y agentes inteligentes.
- Funciona en conjunto con Langchain, pero también puede operar de manera independiente.

- **Acelera el proceso de desarrollo y despliegue de aplicaciones LLM permitiendo pruebas y correcciones en tiempo real.**

# LangServe

- Facilita el despliegue y mantenimiento de aplicaciones utilizando Langchain, convirtiendo aplicaciones de modelos de lenguaje en servidores API de manera rápida y eficiente.

- Construido con FastAPI, LangServe proporciona una API, documentación automática y un espacio de pruebas para tus aplicaciones de LangChaing

- Por defecto, todas las entradas y salidas del servidor se registran automáticamente con LangSmith.
